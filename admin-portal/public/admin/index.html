Set up two-factor sign-in

Needed once. After this, every sign-in asks for a 6-digit code from your phone.

  1. Install Google Authenticator or Microsoft Authenticator on your phone.
  2. In the app, add an account and scan this code.
  3. Type the 6-digit code the app shows.

Two-factor authentication

Enter the 6-digit code from your authenticator app. It changes every 30 seconds.

Lost your phone? Another administrator removes your old authenticator in Supabase (Authentication → Users), and you set it up again at your next sign-in.
